## 怎么用

- **直接读**：打开 `HowToReadGoodBook.html`（单文件，离线可用）或读 `.md` 源。
- **让 AI 帮你查**：安装 `skills/taoge-distill-bottle`（饕哥读书蒸馏瓶），直接问「哪本书讲储蓄率最高」「纳瓦尔的幸福公式是什么」，它会先查书目索引再按口径回答并注明出自第几节。
- **生成 PDF**（本地，需要 Chrome）：

```bash
google-chrome --headless=new --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=HowToReadGoodBook.pdf HowToReadGoodBook.html
```

- **完整阅读记录**（平台声量明细、思维导图、小红书配图、检索总表）在个人读书系统，本仓库只存蒸馏后的精华。
